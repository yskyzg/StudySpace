# StudySpace

> 一个离线优先的番茄专注与学习管理 App。
> 单文件 Web 应用 + Capacitor 打包成 Android APK，数据全部保存在手机本机。

**当前版本：v1.1.0** ｜ 协议：MIT License ｜ 平台：Android 8.0+（APK）／任意现代浏览器（网页版）

---

## 这是什么

StudySpace 从一个单文件番茄学习站重构而来，目标是做成一台能装进手机、长期使用的学习工具，而不是演示页面：

- **打开就是空白状态**：没有预设科目，没有假数据，科目、计划、目标都由自己建立。
- **离线优先**：不需要账号、不上传学习记录、不接云端数据库，`localStorage` 主存 + 影子备份，刷新、息屏、重启都不丢。
- **单文件应用**：`index.html` 内含全部 HTML / CSS / JS，零前端框架、零构建步骤；Capacitor 只负责套上原生外壳与调用系统能力。
- **视觉**：中国复古配色（黛蓝／朱红／藤黄）+ 暖黄信纸底，暂不提供深色模式。

## 主要功能

| 页面 | 能做什么 |
|---|---|
| 首页 | 日目标进度、今日番茄、连续打卡、今日待办、近 7 天学习趋势、基于真实数据的智能提醒（可展开并直达对应页面） |
| 专注 | 倒计时／正向计时、科目选择、时长与休息设置、暂停后继续、超时后显示 `+mm:ss` 并按总时长记录、「结束并记录已专注时长」 |
| 计划 | 今日／长期计划、可编辑、计划月历、按年→月归档、归档可删除 |
| 学习目标 | 日／周达成环、分科目目标、**打卡月历**（点日期看当天时长、番茄数与科目分布） |
| 学习统计 | 多张图表、科目／题型／周期筛选、触屏或鼠标查看节点数据、统计精确到秒 |
| 错题本 | 录入（可附图片）、题型按科目联动、「未分类」筛选、批量选择与导出、1/3/7 天复习节奏、问 AI |
| 复盘 / 周报 | 四段式复盘、历史与导出；周报由计时数据实时生成 |
| AI 助手 | 多会话、每个会话独立选择**提示词预设**、真实 OpenAI 兼容接口（App 内走原生 HTTP，避开 WebView 跨域）、可编辑的上下文接力摘要、接口失败自动降级本地模拟 |
| 科目管理 | 自建科目、12 色色板、按科目维护题型 |
| 设置 | AI 接口与提示词预设、通知诊断、专注提示音、导出备份 JSON／导入、选择式清理数据、关于 |

**专注时的原生能力**

- 开始专注就在通知栏挂一条「已开始专注」常驻通知；倒计时到点另弹一条「专注完成！」，息屏／后台也能收到。
- 提示音：开始、结束、15 分钟、最后 5 分钟各自独立开关，可试听、上传音乐或还原系统音。「最后 5 分钟」只在大于 1 小时的倒计时生效；倒计时到点响过后，手动结束是否再响一次由「计时设置 → 结束后再响一次」控制。

**打卡判定**：当天有专注记录（时长 > 0）即打卡；达到日目标额外标红为「达标」。计划完成、错题复习、日目标都不参与判定，今天还没学不算断。

**清理数据**：可单独清空计时、学习目标、计划、科目、错题、复盘、周报、AI 聊天记录，或一次性清空全部；清理后学习统计、趋势、月历、周报会同步重算。

## 数据与隐私

- 学习记录、设置、AI 会话与 API Key 只存在你手机本地，仓库里不包含任何个人数据。
- 仓库是公开的：**不要把真实 API Key 写进代码文件上传**，只在本机 App 的「设置 → AI 接口」里填写。
- 「导出备份（JSON）」通过系统分享保存到本机 Documents；重要数据建议定期备份。
- 新 APK 使用仓库内 `android.keystore.b64` 固定签名，`versionCode` 随构建递增，**后续覆盖安装会保留数据**。
  > 若手机上装的是固定签名方案之前的旧包，首次升级仍会提示「软件包冲突」：先导出备份 → 卸载旧包 → 装新包 → 导入备份。这一次之后即可无损覆盖。
  > 请勿删除 `android.keystore.b64`，也不要改 `capacitor.config.json` 里的 `appId`。

## 本地预览

直接双击 `index.html` 用浏览器打开即可，无需安装依赖。也可以起一个静态服务：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

浏览器环境下，系统通知、原生文件导出／分享、原生 HTTP 会走降级路径（或不可用），完整体验以 APK 为准。

## 打包 Android APK

推送到 `main` 分支后，GitHub Actions 的「构建安卓 APK」会自动运行，也可以在 Actions 页面手动 `Run workflow`：

1. 等构建出现绿色对勾；
2. 在该次运行页底部 `Artifacts` 下载 **`StudySpace-APK`**；
3. 解压 zip 得到 `app-debug.apk`，传到手机安装（需允许「未知来源」）。

流程内部会自动建 `www/` 并放入 `index.html`（对应 `webDir: "www"`）、安装依赖、生成桌面图标、写入固定签名，最后输出 APK 的 SHA256 签名指纹供核对。

零基础逐步图文说明见 [打包APK操作手册.md](打包APK操作手册.md)。

## 项目结构

```text
StudySpace/
├── index.html                       应用全部代码（单文件 HTML/CSS/JS）
├── capacitor.config.json            appId / appName / webDir / 原生插件配置
├── package.json                     Capacitor 依赖与脚本
├── android.keystore.b64             固定 debug 签名密钥（勿删）
├── assets/logo.svg                  图标与启动图源图
├── .github/workflows/build-apk.yml  自动打包 workflow
├── README.md                        本文件
├── 打包APK操作手册.md                零基础打包与常见问题
├── PRD_番茄学习助手_APK重构.md       产品范围
├── 功能设计清单.md                   功能分布与逐项清单
└── 界面与交互设计规格.md             视觉与交互规格
```

> 仓库里的 `index.html` 位于根目录，是 GitHub 网页上传的扁平结构；Actions 会在构建时自动整理成 Capacitor 需要的 `www/` 目录。
