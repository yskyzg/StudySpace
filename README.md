# StudySpace

> 一个离线优先的番茄专注与学习管理 App。
> 单文件 Web 应用 + Capacitor 打包成 Android APK，数据全部保存在手机本机。

**当前版本：v1.2.0** ｜ 协议：MIT License ｜ 平台：Android 8.0+（APK）／任意现代浏览器（网页版）

---

## 这是什么

StudySpace 从一个单文件番茄学习站重构而来，目标是做成一台能装进手机、长期使用的学习工具，而不是演示页面：

- **打开就是空白状态**：没有预设科目，没有假数据，科目、计划、目标都由自己建立。
- **离线优先**：不需要账号、不上传学习记录、不接云端数据库，`localStorage` 主存 + 影子备份，刷新、息屏、重启都不丢。
- **单文件应用**：`index.html` 内含全部 HTML / CSS / JS，零前端框架、零构建步骤；Capacitor 只负责套上原生外壳与调用系统能力。
- **视觉**：中国复古配色（黛蓝／朱红／藤黄）+ 暖黄信纸底，暂不提供深色模式。圆角四档、双层阴影与纸面纹理统一为设计令牌，分段控件、卡片、列表行、汇总小格、弹层各有一套固定语言（见《界面与交互设计规格》3.6）。

## 主要功能

| 页面 | 能做什么 |
|---|---|
| 首页 | 日目标进度、今日番茄（点「记录 ›」进番茄记录页）、连续打卡、**长期计划倒计时与完成进度条**、「今天该做」时间轴（**逾期未完成排最前并注明原定日期／逾期天数**，今日做完后显示「接下来」次日预览）、近 7 天学习趋势、基于真实数据的智能提醒 |
| 专注 | **今日概览封面**（衬线大分钟数 + 日目标藤黄进度条 + 今日番茄／连续打卡／目标进度三格 + 当前关联计划）；下方会话卡把倒计时／正向计时分段、科目与关联计划下拉、纸面表盘、主操作与「结束并记录」收在一起；时长与休息设置默认折叠，「今日专注分布」按科目加色点；暂停后继续、超时显示 `+mm:ss` 并按总时长记录 |
| 计划 | 顶部**今日概览封面**（衬线大日期 + 完成率进度条 + 待完成／已完成／逾期三格；新增与归档按钮收在卡内，**不再吸顶挡内容**）；每条任务两行排版（标题与「去专注」一行、日期徽章与科目／题型／预计／已专注副信息一行）；新增／编辑时可**指定日期**；按「逾期未完成 → 待完成 → 已完成 → 即将到来」分组（每组带同色竖标），**每组都能一键收起／展开**（状态记在本机，计划再多也不占页面），到设定日期自动变成当天计划；计划月历**归档后仍显示每天计划**、标出**长期计划截止日**、点日期可**标记完成／取消完成**或恢复归档；**独立的长期计划区块**（目标日期、剩余天数、进度调整、进行中列表可收起、标记完成后移入「已完成」分组、单条归档），不与日常计划混排 |
| 番茄记录 | 按日期查看每条番茄的时长／科目／来源标签，删除单条，**补记没打开 App 时完成的番茄**；增删后所有统计实时同步 |
| 学习目标 | 日／周达成环、分科目目标、**科目·明细**（年／月／日三级筛选，点柱状图任意一天看当天时长、番茄数与计划数，下方列出该范围的番茄钟明细与计划详情）、**打卡月历**（点日期看当天时长、番茄数与科目分布） |
| 学习统计 | 多张图表、科目／题型筛选、触屏或鼠标查看节点数据、统计精确到秒；时间范围用「**近期**」下拉（近 7 天／近 30 天）或「**年 + 月**」两级下拉选任意历史月份，**所有图表统一按所选范围统计** |
| 错题本 | 录入（可附图片）、题型按科目联动、「未分类」筛选、批量选择与导出、1/3/7 天复习节奏、问 AI |
| 复盘 / 周报 | 四段式复盘、历史与导出；周报由计时数据实时生成 |
| AI 助手 | 多会话、每个会话独立选择**提示词预设**、真实 OpenAI 兼容接口（App 内走原生 HTTP，避开 WebView 跨域）、可编辑的上下文接力摘要、接口失败自动降级本地模拟 |
| 科目管理 | 自建科目、12 色色板、按科目维护题型 |
| 设置 | AI 接口与提示词预设、通知诊断、专注提示音、导出备份 JSON／导入、选择式清理数据、关于（**归档是内容页，入口只在「我的 → 系统」保留一处**，设置页不重复） |

**专注时的原生能力**

- 开始专注就在通知栏挂一条「已开始专注」常驻通知；倒计时到点另弹一条「专注完成！」，息屏／后台也能收到。
- 提示音：开始、结束、15 分钟、最后 5 分钟各自独立开关，可试听、上传音乐或还原系统音。「最后 5 分钟」只在大于 1 小时的倒计时生效；倒计时到点响过后，手动结束是否再响一次由「计时设置 → 结束后再响一次」控制。

**打卡判定**：只认当天已经发生的事实——**有真实专注记录（时长 > 0，App 内计时或补记番茄都算）**，或**当天计划已勾选完成**，二者满足其一即打卡。只是新建了计划、或点过「开始专注」但没落下记录，都不算打卡；取消勾选后该项也不再支撑打卡。来源标记（`focus` / `plan`）只用于「清理数据」按类撤销，不参与判定，残留标记不会让某天误显示已打卡。达到日目标额外标红为「达标」，错题复习与日目标数字不参与判定，今天还没学不算断。

**计划时间轴**：以往**未完成**的计划不会消失，会一直留在首页／计划页的「逾期未完成」里并注明原定日期与逾期天数，提醒补做；未来计划先在「即将到来」显示，到设定日期自动进入「今天」。今天的任务全部完成后，首页才显示「接下来」的次日计划预览。

**计划 ↔ 番茄钟**：首页「今天该做」、计划页每条待完成计划、计划月历的当日详情里都有「▶ 去专注」——点一下跳到专注页、带入这条计划的科目并完成绑定，**不会自动开始计时**；倒计时时长会自动设成这条计划的「预计时间」（没填则沿用原来的设置），你随时可以切到正计时自己计，什么时候开始也由你定。也可以在专注页的「本次关联计划」下拉里自选，或者干脆不选。倒计时到点、或点「结束并记录已专注时长」时，关联计划会自动打勾（归档里的逾期快照同步更新），会话里会留下 `planId` 与 `planTitle`，番茄记录页能看到归属计划；已专注分钟会累加到计划的「已专注」上。**计时中（或有未结束的进度）不能再从别的计划点「去专注」改绑**：会弹窗说明当前正在专注哪一条，必须选「结束并记录」把这段落库、或「重置时长」放弃这段进度，才能换到新计划（专注页的下拉同样受此限制）。

**界面交互**：所有说明性文字都收成小 `ⓘ` 图标（内联 SVG），点一下在图标下方展开，点其它任何位置或滚动即收起，页面不再被大段注释占位；计划页各分组标题右侧有收起／展开箭头，收起后只留标题与计数。做任何操作（勾选计划、存弹层、归档、补记番茄等）重绘时**保持当前页面与滚动位置**，不再跳回顶部；重新打开 App 会回到上次停留的页面和位置。数据仍照常写入 `localStorage` 主槽＋影子备份，界面状态单独存放，互不影响。

**视觉统一**：全站共用一套「澄净宣纸」语言——圆角四档（20/16/12/9）、暖色双层阴影三档、纸面天光与极淡噪点；分段控件统一为「米色凹槽 + 选中段白纸浮起」，关键数字用衬线等宽数字，汇总小格统一为纸槽底，列表用发丝线分隔、动作收成小胶囊。本期把首页／计划页／统计页的样板铺到了专注、番茄记录、学习目标、科目管理、科目·明细、周报、错题本、复盘、我的、设置、关于、归档与全部弹层：我的页三组菜单各配专属图标，设置卡片内不再出现「框中框」，科目用彩色首字方块，错题待复习改成左侧朱红竖标，归档条目改成两行结构不再挤压换行，弹层加了拖拽短条并统一了输入框／下拉／文件选择／进度滑杆。图表坐标轴改为取整刻度（不再出现 47、103 这种数），末尾日期标签贴边对齐不会被裁掉。

**归档规则**：计划页「归档整理」把**今天及以往已完成的日常计划、已完成的长期计划**移进「归档」，常用区域立即清空（待完成区保持「今天的任务都完成了 ✓」，已完成卡片自动收起），今天完成率仍把归档掉的已完成计划算进去。以往**未完成**的计划属于欠债，不会被归档吞掉。归档只搬位置、不删数据：**计划月历和「点日期看当天计划」仍能看到归档的每一天**（带「已归档」标记），并可直接在这条上「✓ 完成／↺ 取消完成」或「↩ 恢复」；取消完成的状态会同步写回归档记录。归档页支持「年 → 月」两级筛选和**跨年月的「全部归档」视图**，分「目标归档／计划归档／长期计划归档」三组；每条归档都保存完整数据，可恢复或删除。进行中的长期计划不会被批量归档，需要时可在卡片上点「归档 ›」单独归档。长期计划（含已归档）的目标日期在月历上用藤黄底色和 ◆ 标记，点该日期可看到当天到期的计划。只有「清空所有数据」才会清掉归档记录。

**清理数据**：可单独清空计时（含补记番茄记录）、学习目标、计划（含长期计划）、科目、错题、复盘、周报、AI 聊天记录，或一次性清空全部；清理后番茄记录页、学习统计、趋势、月历、周报与首页倒计时会同步重算。「清空计划」保留已归档记录。

## 数据与隐私

- 学习记录、设置、AI 会话与 API Key 只存在你手机本地，仓库里不包含任何个人数据。
- 仓库是公开的：**不要把真实 API Key 写进代码文件上传**，只在本机 App 的「设置 → AI 接口」里填写。
- 「导出备份（JSON）」通过系统分享保存到本机 Documents；重要数据建议定期备份。
- 新 APK 使用仓库内 `android.keystore.b64` 固定签名，`versionCode` 随构建递增，**后续覆盖安装会保留数据**。
  > 若手机上装的是固定签名方案之前的旧包，首次升级仍会提示「软件包冲突」：先导出备份 → 卸载旧包 → 装新包 → 导入备份。这一次之后即可无损覆盖。
  > 请勿删除 `android.keystore.b64`，也不要改 `capacitor.config.json` 里的 `appId`。

## 本地预览

直接双击 `index.html` 用浏览器打开即可，无需安装依赖。也可以起一个静态服务：

```bash
python -m http.server 8080
# 浏览器访问 http://localhost:8080
```

浏览器环境下，系统通知、原生文件导出／分享、原生 HTTP 会走降级路径（或不可用），完整体验以 APK 为准。

## 打包 Android APK

推送到 `main` 分支后，GitHub Actions 的「构建安卓 APK」会自动运行，也可以在 Actions 页面手动 `Run workflow`：

1. 等构建出现绿色对勾；
2. 在该次运行页底部 `Artifacts` 下载 **`StudySpace-APK`**；
3. 解压 zip 得到 `app-debug.apk`，传到手机安装（需允许「未知来源」）。

流程内部会自动建 `www/` 并放入 `index.html`（对应 `webDir: "www"`）、安装依赖、生成桌面图标、写入固定签名，最后输出 APK 的 SHA256 签名指纹供核对。

零基础逐步图文说明见 [打包APK操作手册.md](打包APK操作手册.md)。

## 项目结构

```text
StudySpace/
├── index.html                       应用全部代码（单文件 HTML/CSS/JS）
├── capacitor.config.json            appId / appName / webDir / 原生插件配置
├── package.json                     Capacitor 依赖与脚本
├── android.keystore.b64             固定 debug 签名密钥（勿删）
├── assets/logo.svg                  图标与启动图源图
├── .github/workflows/build-apk.yml  自动打包 workflow
├── README.md                        本文件
├── 打包APK操作手册.md                零基础打包与常见问题
├── PRD_番茄学习助手_APK重构.md       产品范围
├── 功能设计清单.md                   功能分布与逐项清单
└── 界面与交互设计规格.md             视觉与交互规格
```

> 仓库里的 `index.html` 位于根目录，是 GitHub 网页上传的扁平结构；Actions 会在构建时自动整理成 Capacitor 需要的 `www/` 目录。
